# 학습법 문서

학습법 작업은 아래 기준 문서부터 확인한다.

| 문서 | 범위 |
| --- | --- |
| [데이터·API·권한](data-api.md) | 저장 위치, DB 모델, API, 권한, 충돌 처리, 코드 책임, 검증 |
| [입력·UI](ui.md) | 입력 항목과 화면 동작 |
| [운영 절차](operations.md) | migration 적용, 검증, 배포, 복구 |

## 문서 유지 규칙

학습법의 UI·동작·데이터·API·권한·코드 구조를 변경할 때 관련 문서를 같은 작업에서 반드시 갱신한다. 새 요구에 맞지 않는 기존 설명은 수정하거나 제거해 현재 구현과 일치시킨다.

- UI·사용 흐름은 `ui.md`, 저장·API·권한·코드 책임은 `data-api.md`에 기록한다.
- DB 변경·검증 결과·로컬/운영 적용 상태·배포 절차는 `operations.md`에 기록하고, 과거 기록과 현재 상태를 구분한다.
- 질문 참조·등록 안내처럼 다른 도메인과 연결되면 해당 도메인의 기준 문서도 함께 갱신한다. 등록 안내 카드의 제작/응답 계약은 [질문 문서](../questions/ui.md#질문지-시작-안내), 적용 기록은 [질문 운영 문서](../questions/operations.md#재사용-학습법-등록-안내-카드-2026-10-12)를 따른다.
- 파일을 추가·이동하면 이 목록과 관련 링크를 갱신한다. `AGENTS.md`에는 문서 매핑과 갱신 규칙만 두고 상세 구현이나 작업 이력을 중복 기록하지 않는다.

여러 화면에 걸친 디자인 작업 이력은 [UI·UX 작업 기록](../ui-ux-refinement.md)에 남긴다.
