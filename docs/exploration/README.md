# 탐구활동 문서

탐구활동 작업은 아래 기준 문서를 먼저 확인한다.

| 문서 | 범위 |
| --- | --- |
| [데이터·API·권한](data-api.md) | 저장 모델·API·권한·충돌/삭제·코드 책임 |
| [입력·UI](ui.md) | 목록·작성·읽기 전용·참조 흐름 |
| [운영·검증](operations.md) | migration·로컬/운영 상태·검증·배포·복구 |

변경한 UI·동작·데이터·API·권한·코드 구조에 해당하는 문서를 같은 작업에서 반드시 갱신한다. 현재 구현과 맞지 않는 내용은 수정하거나 제거한다. 질문 참조/등록 계약을 바꾸면 [질문 문서](../questions.md)도 갱신한다.

AGENTS.md에는 문서 매핑과 핵심 작업 규칙만 유지하고, 상세 구현·적용 이력을 중복 기록하지 않는다. 화면별 개선의 변경 이력은 [UI·UX 기록](../ui-ux-refinement.md)에 남긴다. 파일을 추가·이동하면 이 목록과 연결된 링크도 갱신한다.
