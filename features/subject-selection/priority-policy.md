# MEA Core 정책 (2026-09-15)

대학은 참고 자료이며 MEA 내부 기준이 우선이다. 대학별 권장 규칙은 별도로 유지한다.

## 구성

- 지정 Core: 개별 필수 과목. 한 학기만 개설되면 자동 선택하고, 여러 학기에 있으면 이수 학기를 고른다.
- 선택형 Core: 후보 중 최소 과목 수와 추가 포함 조건을 충족하도록 학생이 고른다.
- 두 조건 모두 1스테이지의 1단계에서 확인하고 확정한다. 학교지정과 1학년 기이수도 포함하며 같은 이름은 한 과목으로 센다.
- 선택하지 않은 심화 과목은 Sub core로 다음 진로 과목 단계에 남긴다. 대학 요구를 합산해 Core를 늘리지 않는다.

## 과학 심화 조건

| 학과 | 지정 심화 Core | 선택형 Core |
| --- | --- | --- |
| 기계·항공·조선·건축공학·토목·도시·건설환경 | 역학과 에너지 | 없음 |
| 전기전자·전자·반도체 | 전자기와 양자 | 없음 |
| 물리학 | 물리 심화 2개 | 없음 |
| 화학공학·화학생명·화공생명 | 없음 | 물리·화학 심화 4개 중 2개, 화학 심화 최소 1개 포함 |
| 신소재·재료 | 없음 | 물리·화학 심화 4개 중 2개 |
| 에너지·원자력 | 역학과 에너지 | 전자기와 양자·화학 심화 중 1개 |
| 생명·식품공학 | 없음 | 생명 심화 2개 중 1개 |
| 환경공학 | 없음 | 화학 심화 2개 중 1개 |
| 화학과 | 화학 심화 2개 | 없음 |
| 생명과학·생물학 | 생명 심화 2개 | 없음 |
| 지구과학·천문·우주 | 없음 | 지구 심화 2개 중 1개 |
| 의약학 등 화학·생물형 | 없음 | 생명·화학 심화 4개 중 2개 |

기본 과학·수학·정보 Core는 기존 유형을 유지한다. 예: 화학공학은 미적분 II·기하·물리학·화학, 생명공학은 미적분 II·화학·생명과학이다.
컴퓨팅·통계·건축학은 과학 심화 조건을 강제하지 않는다.

## 구현

추천 기준 파일의 기본 유형에 학과별 보정을 적용한다. `findPriorityProfile`은 보정된 Core와 `coreChoices`를 반환한다. `coreChoiceStatuses`는 조건별 현재 수와 충족 여부를 계산한다.
후보는 실제 학기별 선택군에서 선택한다. 미개설·정원 문제로 조건을 충족할 수 없으면 확인이 필요하며, 자동 면제하지 않는다.
기존 학생 선택을 자동 초기화하지 않는다. 변경 기준은 학과를 다시 적용해 확인한다.
