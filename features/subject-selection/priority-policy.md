# MEA Core 정책 (2026-09-15)

대학은 참고 자료이며 MEA 내부 기준이 우선이다. 대학별 권장 규칙은 별도로 유지한다.

## 구성

- 지정 Core: 개별 필수 과목. 한 학기만 개설되면 자동 선택하고, 여러 학기에 있으면 이수 학기를 고른다.
- 선택형 Core: 후보 중 최소 과목 수와 추가 포함 조건을 충족하도록 학생이 고른다.
- 두 조건 모두 1스테이지의 1단계에서 확인하고 확정한다. 학교지정과 1학년 기이수도 포함하며 같은 이름은 한 과목으로 센다.
- 선택하지 않은 심화 과목은 Sub core로 다음 진로 과목 단계에 남긴다. 대학 요구를 합산해 Core를 늘리지 않는다.

기본 과학·수학·정보 Core는 기존 유형을 유지한다. 예: 화학공학은 미적분 II·기하·물리학·화학, 생명공학은 미적분 II·화학·생명과학이다.
컴퓨팅·통계·건축학은 과학 심화 조건을 강제하지 않는다.

## 인문사회 Core 및 Sub core (2026-09-17)

대학의 공식 지원 필수조건이 아닌 MEA 내부 상담 기준이다. Core는 전공의 기초를 고정하고, Sub core는 관심 방향에 따라 선택한다. Sub core 전체 이수를 강제하지 않는다.

### 인문사회 추천 위계 점검

Sub core는 세부 진로와 무관하게 직접적인 학문 기반으로 강하게 권하는 과목이다. 개별 추천은 특정 관심 방향·응용·표현 방식에 도움이 되는 과목이며 학생의 관심과 학업 부담에 따라 대체할 수 있다. 대학 공식 기준이 아닌 메아 내부 정책이며 Core와 대학별 목록은 변경하지 않는다.

| 학과 | Sub core에서 개별 추천으로 조정 | 이유 |
| --- | --- | --- |
| 광고홍보 | 경제, 실용 통계, 문학과 영상 | 시장·효과 분석·영상 제작은 세부 방향에 따른 확장 |
| 미디어 | 문학과 영상 | 영상 표현은 미디어 전체의 공통 기반과 구분 |
| 경영 | 사회와 문화, 인간과 심리 | 조직·소비자 이해 방향의 확장. 이전 지정한 미적분 II는 유지 |
| 경제 | 실용 통계, 금융과 경제생활 | 통계 기반은 확률과 통계로 확보하고 응용·생활금융은 추천 |
| 무역·국제통상·국제 | 세계시민과 지리 | 지역·공간적 맥락의 보완 |
| 행정 | 경제 | 재정·경제정책 방향의 보완 |
| 법·사회복지 | 현대사회와 윤리 | 윤리적 쟁점 탐구의 보완 |
| 철학 | 인문학과 윤리 | 철학·논리 기반과 구분한 윤리 응용 |
| 심리·상담심리 | 생명과학 | 생물·신경심리 방향의 보완. 인간과 심리·실용 통계는 유지 |

어문·역사·윤리교육·정치외교·사회학은 기존 Sub core가 직접 기반에 해당해 유지한다. 내려간 과목은 삭제하지 않고 `recommendCourses`에 남겨 초안·태그·상담에 같은 위계로 반영한다.

광고홍보는 영상 제작뿐 아니라 사회 이해·설득·조사 기반을 반영한다. 경제수학은 경영·국제에 일괄 강제하지 않으며, 심리는 통계 기반을 포함한다.
제2외국어는 현재 과목 데이터가 언어별로 구분되지 않아 특정 언어 Sub core를 임의로 생성하지 않는다. 제2외국어 추천 과목군은 유지한다.
확률과 통계 등 학교지정·1학년 기이수 과목은 기존 이수 판정으로 충족하며 중복 선택하지 않는다.

## 구현

### 기본 추천의 동급 우선순위

Sub core > 개별 추천 > 추천 과목군 > 관련 영역 > 기타 등급을 유지한다. `withinTierPreferences`는 같은 등급 안에서만 우선하는 과목과 이유를 기록한다. 기본형에서는 25점, 상담에서는 0.5점을 더해 상위 등급을 넘지 않도록 한다. `recommendation-focus.ts`에서 전체 유형의 학문적 연결을 점검하고 학과별 보정을 관리한다. 건축학의 공간·지역 우선순위를 무관한 학과에 그대로 확장하지 않는다.

의학·치의학·한의학·약학·간호는 화학·생명 Core/Sub core를 유지하고, 현대사회와 윤리·윤리문제 탐구 중 한 과목을 추가 물리 심화보다 먼저 고려한다. 사회 전체를 추천하지 않으며 윤리를 필수나 Sub core로 승격하지 않는다. 기본형 생성 시 `draftRecommendationGroups`는 기이수·학교지정·1단계 확정·이미 추천한 과목을 포함해 한 과목이 있으면 두 번째 윤리의 개별 추천 가점을 해제한다. 빈자리가 윤리 과목만 허용하면 두 번째도 선택할 수 있다. 이 묶음은 기본형의 폭넓은 구성을 위한 선호이지 이수 조건이 아니다. 복수형의 양쪽 학과 준비 점수는 기존 방식을 유지한다.

통계·컴퓨팅·생명·심리는 통계 과목을 개별 추천으로 보완한다. 도시공학·지리학은 지리 과목을, 산업공학은 경제·경제수학을 명시적으로 추천한다. 나머지 유형은 물리·화학적 연결, 환경·기후, 언어·문화, 역사·공간, 제도·사회문제 등 직접 연결 과목을 같은 등급 내에서 우선한다. 이 기준은 메아의 교육적 추천이며 대학의 공식 필수·권장 과목이나 입시 유불리를 뜻하지 않는다. 기존 Core와 대학별 공식 목록은 변경하지 않는다.

새로 추가한 개별 추천은 `breadthCourses`로도 기록한다. 이 이름만으로 복수학과의 심화 과목 수·공통 학문 기반 수를 늘리지 않는다. 해당 학과의 기존 Core/Sub core 또는 과학 심화 기준에도 해당하면 그 기존 근거는 그대로 인정한다.

경제수학은 Core·선택형 Core·Sub core·개별 추천에 명시된 경우에만 영역 추천을 인정한다. 수학 추천 과목군 및 Core와 같은 수학 영역이라는 이유만으로 점수를 주지 않는다. 초안·내부 추천 배지·상담에 동일한 예외를 적용하되 대학의 공식 권장 표시는 변경하지 않는다. 학생의 직접 선택은 제한하지 않으며, 다른 후보가 없으면 기타 과목으로 초안에 포함될 수 있다.

추천 기준 파일의 기본 유형에 학과별 보정을 적용한다. `findPriorityProfile`은 보정된 Core와 `coreChoices`를 반환한다. `coreChoiceStatuses`는 조건별 현재 수와 충족 여부를 계산한다.
후보는 실제 학기별 선택군에서 선택한다. 미개설·정원 문제로 조건을 충족할 수 없으면 확인이 필요하며, 자동 면제하지 않는다.
기존 학생 선택을 자동 초기화하지 않는다. 변경 기준은 학과를 다시 적용해 확인한다.
