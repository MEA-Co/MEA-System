# 복수 학과 병행 검토 기준

메아의 내부 상담 정책이다. 학문적 연결의 불가능이나 대학의 공식 지원 요건을 판정하지 않는다.

## 세 가지 연결 경로

1. 학문 기반 공유: 양쪽 코어·심화로 인정되는 과목을 2개 이상 확보한다.
2. 연구 방법 공유: `major-relationships.ts`에 학과명으로 명시된 관계이며, 분석 방법과 상대 학문 자체의 기반을 모두 확보한다. 넓은 추천 영역이나 학과명 유사성만으로 관계를 확대하지 않는다.
3. 인문사회 학문적 접점: `humanities-relationships.ts`에 등록된 조직·시장·사회, 언어·문학·문화 등의 접점으로 검토한다. 동일한 과목 2개를 요구하지 않는다. 과목명 중복은 준비 효율의 참고 지표일 뿐이며 각 전공의 Core·Sub core 준비를 대신하지 않는다.

인문사회 접점은 경영·무역·국제와 사회학·사회복지, 어문과 사회학·사회복지, 경영·무역·국제와 영어영문, 경제와 경영·무역·국제, 정치·행정·법과 사회학·사회복지, 역사와 어문, 미디어와 사회학·사회복지에 한해 등록한다. 경영·영어영문은 업무용 영어가 아닌 영문학 자체의 관심이 필요하다. 자연·공학과 인문사회 조합에 이 경로를 자동 확장하지 않는다.

| 조합                            | 내부 검토 방향                                 | 연결에 필요한 과목                                                     |
| ------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------- |
| 데이터과학·통계 + 심리·상담심리 | 연구 방법 공유로 검토                          | 확률과 통계·인공지능 수학·데이터 과학 중 2개 + 사회와 문화·인간과 심리 |
| 데이터과학·통계 + 행정          | 정책 평가·공공데이터 분석 방향에서 조건부 검토 | 위 분석 기반 2개 + 정치·법과 사회·사회와 문화                          |
| 데이터과학 + 국어국문학         | 기본 병행 전략으로 권하지 않음                 | 텍스트 분석 가능성만으로 국문학 준비를 인정하지 않음                   |
| 에너지공학 + 행정               | 기본 병행 전략으로 권하지 않음                 | 에너지 정책을 배경으로 활용하는 것만으로 양쪽 준비를 인정하지 않음     |

명시적 방법론 관계는 대칭이지만 기존 전공의 우선순위와 유지율 계산은 대칭이 아니다. 행정 관계를 같은 유형의 법학·정치외교학에 자동 적용하지 않는다. 컴퓨터공학 전체에도 데이터과학 관계를 자동 적용하지 않는다. 관계표를 늘릴 때는 독립적인 학문 기반과 구체적인 교과 조건 및 비허용 회귀 사례를 함께 추가한다.

## 판정 순서

- 사전 검토는 1학년 지정·학교지정·전체 선택 후보로 연결 조건과 코어 개설 여부를 확인한다. 가능한 과목을 아직 선택하지 않았다는 이유로 탈락시키지 않는다.
- 연결 기반은 있으나 현재 초안에 코어·선행·방법론 기반 과목이 부족하면 조정 검토다. 방법론에 필요한 과목도 추천·조정 탐색의 대상으로 포함한다.
- 등록된 인문사회 접점이 있지만 현재 초안의 보완 준비나 유지율이 부족하면 비추천 대신 조정 검토로 보낸다. 코어 미개설은 사전 검토에서 별도로 안내한다. 조정안을 찾지 못했다고 학문적 접점 자체가 없다고 단정하지 않는다.
- 최종 병행 가능은 양쪽 코어·선행 조건, 각 전공의 심화 준비, 기존 전공 심화 유지율 75% 이상, 위 세 연결 경로 중 하나를 모두 충족해야 한다. 인문사회 접점과 방법론 관계가 과목 수·졸업요건을 면제하지 않는다.
- 사전 기준을 통과하지 못하면 이유 입력 없이 기본안/다른 학과로 안내한다. 조정 검토에서는 실제 지원 의향만 선택한다. 관심이 있거나 아직 모르겠다면 과목 조정안을 먼저 볼 수 있다. 탐구 자료·독서·활동 계획을 쓰거나 AI 심사를 통과할 필요는 없다. 변경 과목을 제시한 뒤 기존 전공과 추가 학과의 공부를 병행할 부담을 확인하고 학생의 동의를 받아 적용한다. 과목 배치·선행·졸업요건·준비 깊이 검증은 유지한다.

과목 기반 판정은 실제 탐구 활동이나 입시 경쟁력 검증을 대체하지 않는다. 원문 미지원 규칙과 실제 시간표도 별도 확인 대상이다.
