# 학교 편제표 가져오기

선택과목 화면의 `직접 선택` 탭과 독립적으로 학교 공시 원문을 조회하고 검토한다. 탭을 바꿔도 입력 상태는 유지되며, 가져온 선택군을 수동 입력의 학기별 단일 선택 개수로 합치지 않는다. 직접 입력과 가져오기 결과는 확정 시 동일한 학기·학교지정 과목·선택군 모델로 정규화되며, 설정 화면을 닫고 희망 학과 및 편제표를 보여주는 과목 선택 단계로 이동한다. 확정한 결과와 희망 학과는 현재 화면 메모리에만 유지된다. `결과 저장`으로 원문 출처·해시·검증 결과·검토 여부를 포함한 JSON을 내려받는다. DB 저장은 하지 않는다.

## 환경 변수

- `OPENAI_API_KEY`: 문서 분석에 필요. 기존 서버 환경 변수를 사용한다.
- `SCHOOLINFO_API_KEY`: 선택 사항. 설정하면 공식 학교기본정보 API(`apiType=0`)를 조회한다. 없으면 공개 검색 화면의 학교 검색 JSON을 사용한다.
- `SUBJECT_EXTRACTION_MODEL`: 선택 사항. 기본값은 기존 프로젝트에서 사용하는 `gpt-5.6-luna`. PDF 입력과 Structured Outputs를 지원해야 한다.

## 조회 경로

공식 Open API의 제공 목록에는 교육과정 첨부파일이 없다. 공시 원문은 학교알리미 공개 화면의 다음 경로에서 가져온다. 공개 화면용 엔드포인트는 공식 Open API 계약이 아니므로 사이트 변경 시 어댑터를 수정해야 한다.

1. `/ei/ss/pneiss_a04_s0/getSchoolList.do`: EUC-KR 학교명으로 검색하여 공시 UUID 확보.
2. `/ei/pp/Pneipp_b14_s0p.do`: `학교교육과정 편성·운영 및 평가에 관한 사항` (2-가) 공시.
3. `#eiFileDownForm`과 `getEiFile14(FILE_SEQ)`에서 다운로드 매개변수 확보.
4. `/servlets/EiFileDownLoad.do`: 선택한 원문 다운로드. 분석 요청 때 서버에서 목록을 재조회하며 임의 URL은 받지 않는다.

파일명 점수는 추천 순서일 뿐이다. 학사일정도 목록에는 남겨 사용자가 원문을 확인할 수 있다. 편제표 여부와 코호트는 실제 문서 분석에서 다시 확인한다.

한 코호트에 일반·과학중점 등 여러 과정이 있으면 `과정·학과`를 지정한다. 지정하지 않은 상태에서 여러 과정이 발견되면 임의로 하나를 선택하지 않고 과정 지정 필요를 반환한다.

## 추출과 검증

- 매직바이트와 ZIP/OLE 내부 구조로 PDF, HWP5, HWPX, XLS/XLSX, DOCX, HTML 표를 구분한다.
- PDF는 텍스트와 페이지 이미지를 함께 읽을 수 있도록 원문 파일 입력을 사용한다. Excel은 셀과 병합 범위를, HWPX/DOCX는 XML 구조를 전달한다.
- HWP5는 압축 스트림과 레코드 계층을 읽지만 셀 좌표를 완전히 복원하지 못하므로 항상 `review_required`다. 암호화·배포용 HWP는 거절한다.
- 과목 학점, 학교지정 여부, 선택군, 택 N, 후보 수 원문 근거, 연동 규칙, 코호트와 원문 위치를 구조화한다. 없는 값은 null/unknown으로 남긴다.
- 서버가 중복, 선택군 연결, 후보 수, 코호트, 학점 합계를 검사한다. 학점은 필수 과목 + 선택군별 `택 N × 학점`으로 계산한다. 후보마다 학점이 다르거나 복합 규칙이면 임의 계산하지 않는다.
- 모든 추출 학기의 교과 총계와 2-1~3-2 자료를 확인한다. 창체 포함 총계를 교과 총계로 비교하지 않는다. 불명확한 결과는 검토 확인 후에만 수동 확정할 수 있으며 자동 검증 상태는 바꾸지 않는다. 코호트 불일치·미확인과 추출 실패는 확정을 막는다.
- 12MB 원문, 32MB 압축 해제, 24만자 구조화 원문 한도를 둔다. 큰 문서는 편제표 부분을 따로 업로드한다. 서버 인증 및 회원 역할 검사를 사용한다. 프로세스별 사용자 동시 분석은 1건으로 제한한다.

원문 식별과 값의 의미 해석은 모델 추출에 의존한다. `verified`는 추출 근거와 서버의 구조·산술 검증을 통과했다는 의미이며, 원문 대조 없이 정확도를 보장하는 표시는 아니다.

## 전공 연계 과목 선택

편제표 확정 후 희망 학과를 입력하면 `recommendations.ts`의 내부 우선순위 분류 중 가장 가까운 분류를 찾는다. 내부 `Core`만 필수 선택으로 취급하고, `Sub core`와 추천 과목·과목군은 안내로 표시한다. `미기`는 `미적분 II`와 `기하`, `미`는 `미적분 II`, `생물`은 `생명과학`으로 정규화했다.

고려대, 연세대, 경희대, 중앙대의 2028학년도 자료는 대학별 모집단위와 개별 과목 또는 과목군 규칙으로 저장한다. 희망 학과와 충분히 유사한 모집단위가 있는 대학만 표시한다. 경희대의 대학 `핵심과목`은 강한 안내 표시는 제공하지만 내부 `Core`가 아니면 강제하지 않는다. 연세대의 과학 진로선택 3과목 이상과 같은 과목군 조건은 해당 과목군의 편제 과목에 표시한다.

학생 선택은 학교 선택군별 `택 N` 상한을 넘지 못하며, 같은 과목이 여러 학기에 있으면 한 학기의 과목만 선택 상태로 유지한다. 아직 DB에는 저장하지 않는다.
